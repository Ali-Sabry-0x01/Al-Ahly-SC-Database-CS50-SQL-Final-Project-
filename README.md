# 🦅 Al Ahly SC Database System

This repository contains my final project for **Harvard University's CS50 SQL** (Introduction to Databases with SQL). 

I designed and implemented a comprehensive database system for **Al Ahly Sporting Club**. The project demonstrates practical database design principles, schema creation, and complex query formulation.

### 🛠️ Technologies & Features:
- **SQL (SQLite)**
- **Database Design & Entity-Relationship Modeling**
- **Schema Creation** (`schema.sql`)
- **Optimized Queries & Views** (`queries.sql`)

*Developed by Ali Sabry as a capstone project for CS50 SQL.*
